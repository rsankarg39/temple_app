## 🚀 Quick Start Commands

### Step 1: Get Oracle VM IP
```powershell
# After creating VM, note the PUBLIC IP
# Example: 140.x.x.x
```

### Step 2: SSH to VM
```powershell
$keyPath = "$env:USERPROFILE\.ssh\oracle-vm-key.pem"
ssh -i $keyPath ubuntu@<PUBLIC_IP>
```

### Step 3: Install Docker (Copy-Paste)
```bash
sudo apt update && sudo apt upgrade -y
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker ubuntu
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
exit
ssh -i $keyPath ubuntu@<PUBLIC_IP>
```

### Step 4: Deploy Stack
```bash
mkdir -p ~/temple-backend/postgres && cd ~/temple-backend
# Download docker-compose.yml and init.sql from DEPLOYMENT_GUIDE.md
# Then:
docker-compose up -d
sleep 60
docker-compose ps
```

### Step 5: Update Flutter Config
1. Open `supabase_config.dart`
2. Replace `url = 'https://rftkomfjwswquxbhxbdc.supabase.co'` with:
   ```dart
   url = 'http://<PUBLIC_IP>:3000'
   ```
3. Keep the anonKey the same

### Step 6: Build & Test

## 🐛 Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| Can't connect to backend | Check `supabase_config.dart` has correct IP, restart app |
| "Invalid login credentials" | Verify user was registered in DB: `docker exec temple_postgres psql -U postgres -d temple_db -c "SELECT * FROM auth.users;"` |
| Port 3000 not accessible | Check Oracle VM Security List allows inbound port 3000 |
| Docker services won't start | `docker-compose down && docker-compose up -d --build` |
| PostgreSQL not initializing | Check `init.sql` syntax, view logs: `docker logs temple_postgres` |
